# eZion — Next.js ERP Layout (raiz frontend)

Este diretório contém o frontend Next.js para o ERP.

Como usar

1. Entre na pasta do projeto:
```bash
cd frontend
```
2. Instale dependências e rode em modo dev:
```bash
npm install
npm run dev
```
3. Abra `http://localhost:3000`.

Observações
- Se você já possuía `admin-template` em `frontend/admin-template`, ele permanece intacto.
- Caso prefira, remova a pasta `erp-next` antiga que foi substituída.
