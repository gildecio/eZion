## 1. ESTRUTURA HTML PADRÃO

```tsx
<div className="nome-crud">
  <div className="header">
    <div>
      <h1>Título da Tela</h1>
      <p>Descrição/subtítulo da funcionalidade</p>
    </div>
    {!showForm && (
      <button className="btn-new">
        <svg><!-- Ícone + --></svg>
        Cadastrar
      </button>
    )}
  </div>

  <div className="content">
    {showForm ? (
      <div className="form-container">
        <div className="form-header">
          <h2>{editing ? 'Editar' : 'Novo'} Item</h2>
          <button className="btn-close">
            <svg><!-- Ícone X --></svg>
          </button>
        </div>
        <form>
          <div className="form-group">
            <label>Campo <span className="required">*</span></label>
            <input type="text" />
          </div>
          <div className="form-actions">
            <button type="button" className="btn-cancel">Cancelar</button>
            <button type="submit" className="btn-submit">Salvar</button>
          </div>
        </form>
      </div>
    ) : (
      <div className="table-wrapper">
        <table>
          <thead>
            <tr>
              <th>Coluna 1</th>
              <th>Ações</th>
            </tr>
          </thead>
          <tbody>
            <tr>
              <td>Valor</td>
              <td>
                <div className="actions">
                  <button className="btn-edit"><svg><!-- Edit --></svg></button>
                  <button className="btn-delete"><svg><!-- Delete --></svg></button>
                </div>
              </td>
            </tr>
          </tbody>
        </table>
      </div>
    )}
  </div>

  {showDeleteModal && <DeleteConfirmModal />}

  <style jsx>{/* ... */}</style>
</div>
```

## 15. CHECKLIST DE IMPLEMENTAÇÃO

Ao criar um novo CRUD, certifique-se de:

- [ ] Container principal com padding 2rem e max-width 90%
- [ ] Header com título (h1) e descrição (p)
- [ ] Botão "Cadastrar" verde (#556b2f) com ícone +
- [ ] Content com background branco e border-radius 12px
- [ ] Formulário com form-header, form-groups e form-actions
- [ ] Inputs com focus ring verde (#556b2f)
- [ ] Tabela com thead cinza (#f9fafb) e hover nas linhas
- [ ] Botões de ação (editar azul, excluir vermelho)
- [ ] Ícones SVG inline em todos os botões
- [ ] Badges com cores apropriadas
- [ ] Alertas de erro com fundo vermelho claro
- [ ] Estados de loading e empty state
- [ ] Responsividade com breakpoint em 768px
- [ ] Transições suaves (0.2s) em elementos interativos
- [ ] DeleteConfirmModal para confirmação de exclusão
- [ ] Consistent spacing usando rem (0.5rem, 1rem, 1.5rem, 2rem)

## 16. OBSERVAÇÕES IMPORTANTES

1. **Sempre use styled jsx** - não crie arquivos CSS externos
2. **Cores primárias em variáveis** - facilita manutenção futura
3. **Ícones sempre inline** - não use bibliotecas de ícones
4. **Mobile first** - comece com layout mobile e ajuste para desktop
5. **Semântica HTML** - use tags apropriadas (button, form, table)
6. **Acessibilidade** - sempre adicione title nos botões de ação
7. **Consistência** - siga exatamente estes padrões em todos os CRUDs
